# TV Box Turbo ⚡

Aplicativo nativo para Android TV / TV Box focado em reparo, limpeza e aceleração em 3 cliques.

### Funcionalidades:
1. **Limpeza de Memória RAM:** Encerra processos em segundo plano de aplicativos fantasmas.
2. **Limpeza de Cache e Resíduos:** Remove arquivos temporários e lixo acumulado.
3. **Modo Turbo:** Otimiza o processador e resposta do controle remoto.

---
Compilado automaticamente via GitHub Actions.
